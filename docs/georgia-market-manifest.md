# LEX — Вихід на грузинський ринок

## Маніфест

**Дата:** 17 березня 2026

LEX (SecondLayer) досліджує можливість виходу на ринок юридичних технологій Грузії. Грузія є стратегічно привабливим ринком через:

- **Відсутність конкурентів** — не виявлено жодної legal tech платформи з AI-пошуком по грузинському праву
- **Зростаючий стартап-екосистема** — Тбілісі входить в топ-50 міст для стартапів, екосистема оцінюється в ~$240M
- **Реформа Open Data** — очікується прийняття Open Data Act у 2026 році в рамках OGP
- **Схожа правова система** — пострадянська правова традиція, аналогічна українській
- **Парламент має відмінний публічний API** — найкраще джерело даних, готове до інтеграції

## Детальний аналіз по джерелах

### 1. Парламент Грузії — info.parliament.ge 🟢

**Найкраще джерело даних.** Повноцінний REST API з документацією Swagger.

- **Swagger UI:** https://info.parliament.ge/swagger-ui.html
- **OpenAPI spec:** https://info.parliament.ge/v2/api-docs?group=parl.infdep.ge
- **Авторизація:** Не потрібна для read-ендпоінтів
- **Формат:** JSON
- **Ліцензія:** GPLv3
- **Двомовність:** Грузинська + англійська

**Обсяг даних (актуальний, 17.03.2026):**

| Датасет | Кількість | Ендпоінт |
|---------|-----------|----------|
| Законопроекти | 25,625 | `GET /law/1/bill` |
| Пакети законопроектів | 16,512 | `GET /law/1/billPackage` |
| Голосування (сесії) | 18,088 | `GET /law/1/voteSession` |
| Запити депутатів | 14,030 | `GET /mpQuestion/1/` |
| Сесії парламенту | 916 | `GET /law/1/parliamentSession` |
| Депутати (усі скликання) | 1,437 | `GET /hr/colleague/1/` |
| Open data файли | 3,109 | `GET /opendata/1/` |
| Комітети (поточні) | 16 | `GET /hr/structure/1/committees` |

**12 контролерів, ~90+ ендпоінтів:** law, colleague, structure, law-lib, hr-lib, mp-question, open-data, container, file, image, info.

**Аналог у LEX (Україна):** `mcp_rada` — прямий аналог, можна адаптувати.

### 2. Законодавство — matsne.gov.ge 🟡

**Офіційний Законодавчий вісник Грузії.** Оператор — LEPL під Мін'юстом. З 2011 року нормативні акти набувають чинності тільки після публікації на matsne.gov.ge.

- **Обсяг:** ~30,000–60,000 нормативних актів (усі закони, укази, постанови, муніципальні акти)
- **API:** Немає публічного API
- **Структура URL:** Передбачувана — `/document/view/{id}`, `/document/download/{id}/{version}/{lang}/pdf`
- **Мови:** Грузинська, англійська, російська (паралельні тексти)
- **Мобільні додатки:** iOS + Android

**Типи контенту:**
- Органічні закони та закони Грузії
- Постанови, укази, розпорядження
- Міжнародні договори
- Рішення Конституційного суду
- Акти місцевого самоврядування
- Консолідовані версії з повною історією змін

**Стратегія інтеграції:** Скрейпінг через передбачувані URL. ID документів від ~16,000 до ~6,000,000+.

**Аналог у LEX (Україна):** `LegislationService` / `RadaLegislationAdapter` — прямий аналог.

### 3. Бізнес-реєстр — napr.gov.ge 🟡

**Національне агентство публічного реєстру** (LEPL під Мін'юстом).

- **Обсяг:** ~995,678 зареєстрованих суб'єктів, ~274K активних (27%)
- **Офіційний пошук:** enreg.reestri.gov.ge — веб-форма з CAPTCHA, без API
- **Альтернативні джерела:**

| Джерело | Обсяг | Формат | Доступ |
|---------|-------|--------|--------|
| OpenSanctions | 1,393,921 сутностей (693 MB) | JSON, CSV | Bulk download, API (платний для комерції) |
| companyinfo.ge (TI Georgia) | Усі компанії з 2010 | HTML | Веб-інтерфейс, оновлення щомісяця |
| TI Georgia CorpSearch (GitHub) | Скрейпнуті дані | JSON | github.com/tigeorgia/CorpSearch |
| GeoStat | Агреговані дані | Excel/CSV | geostat.ge |

**Аналог у LEX (Україна):** `mcp_openreyestr` — прямий аналог.

### 4. Судові рішення — ecd.court.ge 🔴

**Критична проблема.** Портал заморожений з травня 2020.

- **Причина:** Рішення Конституційного суду (червень 2019) про конфлікт між прозорістю судової влади та захистом персональних даних
- **З 1 січня 2024** закон зобов'язує суди публікувати деперсоналізовані рішення — але суди **не виконують** цю вимогу
- **Верховний суд** — єдиний, що активно публікує рішення: supremecourt.ge/ka/decisions
- **Нижчі суди** — не публікують рішення онлайн

**Моніторинг ситуації:**
- courtwatch.ge — звіти про невиконання закону
- IDFI (idfi.ge) — аналіз доступності судових актів
- OGP Georgia — трекінг зобов'язань

**Стратегія:** Це — можливість, а не перешкода. LEX може:
1. Стати каталізатором публікації рішень через партнерство з громадянським суспільством
2. Розпочати з рішень Верховного суду та Конституційного суду
3. Позиціонуватися як інфраструктурний партнер для реформи

**Аналог у LEX (Україна):** Основний `mcp_backend` / ЄДРСР — але в Грузії аналога ЄДРСР фактично немає.

## Рекомендована стратегія входу

### Фаза 1: Quick Win (1-2 місяці)
1. **mcp_georgia_parliament** — адаптувати mcp_rada для грузинського парламенту (API готовий)
2. **Законодавство через matsne.gov.ge** — скрейпер для нормативних актів

### Фаза 2: Розширення (3-4 місяці)
3. **Бізнес-реєстр** — інтеграція через OpenSanctions bulk data або companyinfo.ge
4. **Верховний суд + Конституційний суд** — скрейпінг рішень

### Фаза 3: Стратегічне позиціонування (6+ місяців)
5. **Партнерство з IDFI / courtwatch.ge** — лобіювання відкриття судових рішень
6. **Партнерство з Мін'юстом** — пілотний проєкт з matsne.gov.ge API
7. **Georgian NLP** — fine-tuning мовних моделей для грузинської юридичної мови
