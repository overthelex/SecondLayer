## Назва задачі (Title)
Внести на сайт публічну оферту та інформацію про товари/послуги з цінами (вимоги Monobank для еквайрингу)

## Опис (Description)

Monobank вимагає перед продовженням підключення еквайрингу додати на сайт:

### 1. Публічна оферта
- Розмістити на сайті **публічну оферту**.
- У ній обов’язково має бути:
  - **Назва компанії** (ТОВ)
  - **Код ЄДРПОУ**
  - **Адреса**

### 2. Інформація про товари або послуги
- Додати на сайт **інформацію про товари або послуги**.
- **Ціни обов’язково в гривні (UAH).**

Після внесення змін — повідомити Monobank, щоб вони продовжили підключення еквайрингу.
