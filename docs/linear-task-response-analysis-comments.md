# Linear Task: Коментарі до логів із відповідями для порівняння та аналізу

**Контекст:** [chat-9e2c294a-response.md](../responce_analisys/chat-9e2c294a-response.md) — приклад експортованого логу (запит + повна відповідь чату). Потрібна можливість додавати до таких логів коментарі для подальшого порівняння та аналізу якості відповідей.

## Назва задачі (Title)
Response analysis: коментарі до логів із відповідями для порівняння та аналізу

## Опис (Description)

### Проблема
Отримані логи чатів з повними відповідями (наприклад, експорт у `docs/responce_analisys/chat-<request_id>-response.md`) не мають механізму коментування. Неможливо позначати місця для покращення, фіксувати оцінки, порівнювати різні відповіді на один і той самий запит.

### Мета
Зробити так, щоб до отриманих логів з відповідями можна було додавати **коментарі** для подальшого порівняння та аналізу (наприклад: оцінка якості, позначки по секціях, порівняння з іншими response_id).

### Вимоги (scope)

1. **Коментарі до логів/відповідей**
   - Можливість додавати коментарі до конкретного логу (файлу/запису з request_id).
   - Коментар має бути прив’язаний до контексту: request_id (або conversation_id), опційно — до фрагменту тексту (секція, абзац).

2. **Зберігання коментарів**
   - Варіанти: окремі файли в `docs/responce_analisys/` (наприклад, `chat-9e2c294a-comments.md` або YAML/JSON), або поле в БД (якщо з’явиться сутність «response review»).
   - Формат коментаря: автор (опційно), дата, текст, опційно — теги (наприклад: «якість», «цитування», «пропуск»).

3. **Порівняння та аналіз**
   - Можливість переглядати один запрос і кілька відповідей (різні response_id) разом із коментарями.
   - Мінімум: список логів з можливістю фільтрації/пошуку та перегляд коментарів біля відповіді.

### Приклад артефакту
- Лог: `docs/responce_analisys/chat-9e2c294a-response.md` (запит + повна відповідь).
- Коментарі: окремий файл або блок у тому ж файлі, наприклад:
  - «Секція 2.1 — добре підібрані справи, додати 910/…»
  - «Резолютивна частина відповідає Matrix Xa»
  - «Порівняти з chat-69bb7b1e…»

### Критерії готовності (Acceptance criteria)
- [ ] Є спосіб додати коментар до логу (ідентифікованого за request_id / файлом).
- [ ] Коментарі зберігаються і відображаються разом із логом або в прив’язці до нього.
- [ ] Є можливість переглянути коментарі для обраного логу та (опційно) порівняти кілька логів з коментарями.
