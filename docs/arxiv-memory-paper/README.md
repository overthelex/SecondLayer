# Workflow Memory for Long-Horizon Agentic Composition

arXiv preprint — companion to "Edit-Trace Oversight: Scalable Alignment Signal from Agentic Workflows"

**Categories:** primary `cs.SE`, secondary `cs.AI`

## Build

Requires TeX Live 2024 (or compatible). No exotic packages.

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Verify: no `??` in the PDF, no undefined references in the log.

## arXiv Submission

1. Compile locally end-to-end, verify clean
2. The `.bbl` file is generated by `bibtex` — include it in the tarball
3. Create submission tarball:

```bash
mkdir -p arxiv-submission
tar czf arxiv-submission/memory-paper.tar.gz \
  main.tex main.bbl \
  figures/architecture.tex figures/dual-mode-timing.tex
```

4. Upload to arXiv, select `cs.SE` primary, `cs.AI` cross-list
5. Comments field: "Companion to arXiv:XXXX.XXXXX. 14 pages, 2 figures."

## File Layout

```
main.tex                  # single-file paper
references.bib            # all citations
figures/
  architecture.tex        # TikZ: three-layer architecture diagram
  dual-mode-timing.tex    # TikZ: 6-week dual-mode timing diagram
```
