1.3. Цей Договір укладено на підставі публічної оферти Виконавця відповідно до ст. 633, 634, 641, 642, 901–907 Цивільного кодексу України. Акцептом оферти є підписання цього Договору або фактичний початок використання API Замовником (залежно від того, що відбудеться раніше).

1.4. **Терміни та визначення.** Для цілей цього Договору терміни вживаються в такому значенні:

- **API (Application Programming Interface)** — програмний інтерфейс для доступу до інформаційної системи Виконавця, що дозволяє Замовнику здійснювати автоматизовані запити до бази правової інформації та сервісів Платформи.
- **Виклик (Запит)** — одиничне звернення до одного інструмента API з метою отримання конкретного результату (фрагмента даних). Одиниця тарифікації.
- **Токен доступу (API-ключ)** — унікальний ідентифікатор, що надається Виконавцем Замовнику для авторизованого використання API.
- **Кредит** — облікова одиниця білінгової системи; 1 кредит = 0,01 USD.
- **Баланс** — сума передоплачених Замовником коштів (у кредитах), з якої списується вартість викликів.
- **Звітний період** — календарний місяць, за який обліковується кількість і вартість викликів.
- **Форс-мажор** — обставини непереборної сили, що унеможливлюють виконання зобов'язань за цим Договором.
- **Сторони** — Виконавець і Замовник, які уклали цей Договір.
