# Шаблон Legal AI для комплексного аналізу однієї справи

> **Професійний шаблон відповіді** для повноцінного аналізу судової справи в усіх інстанціях — від першої до Великої Палати Верховного Суду.

---

## Про цей шаблон

Шаблон задає **єдиний стандарт** того, як Legal AI формує відповідь на запит про комплексний аналіз конкретної справи. Він охоплює весь життєвий цикл справи: хронологію, зміну вимог, доказову базу, позиції судів і результативні висновки для кожної сторони.

**Для кого:** юристи, клієнти, дослідники — усі, хто потребує структурованого, перевіреного й повного розбору справи з посиланнями на ЄДРСР та процесуальні документи.

**Що отримуєте:** один документ з карткою справи, таймлайном подій, еволюцією позовних вимог, оцінкою доказів по інстанціях, позиціями судів (включно з правовою позицією ВП ВС), підсумками для позивача й відповідача та ключовими правовими висновками.

**Структура:** 9 блоків — від вступного підтвердження обсягу й джерел до додатків (схема руху справи, перелік рішень, порівняльна таблиця позицій сторін).

Нижче — повний шаблон з усіма розділами та плейсхолдерами для заповнення.

## 1. ВСТУПНИЙ БЛОК (Acknowledgment & Scope)

```
═══════════════════════════════════════════════════════════════════════
КОМПЛЕКСНИЙ АНАЛІЗ СПРАВИ № [NNNN/NNNN/YY]
═══════════════════════════════════════════════════════════════════════

Виконую комплексний аналіз справи через усі судові інстанції. 

ОБСЯГ АНАЛІЗУ:
├─ Хронологія процесуальних етапів
├─ Еволюція предмету спору та вимог
├─ Оцінка доказової бази
├─ Позиції судів усіх інстанцій
└─ Результативні висновки для кожної сторони

ДЖЕРЕЛА ДАНИХ:
├─ Єдиний державний реєстр судових рішень (ЄДРСР)
└─ Процесуальні документи всіх інстанцій

ОЦІНКА ПОВНОТИ ДАНИХ:
├─ Знайдено судових рішень: [кількість / перелік рішень за інстанціями]
├─ Відсутні або обмежені у доступі рішення/документи: [опис, якщо відомо]
└─ Інші потенційні обмеження даних (закритість, анонімізація тощо): [опис]
```
