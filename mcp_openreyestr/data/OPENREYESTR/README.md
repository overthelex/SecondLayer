# NAIS Open Data -- Legacy Data Workspace

> **Увага:** Це legacy-директорія для початкового дослідження даних НАІС.
> Актуальний MCP-сервер знаходиться у `/mcp_openreyestr/` (кореневий `README.md`).
> Імпорт та синхронізація даних тепер виконуються через скрипти MCP-сервера:
> `npm run import:nais`, `npm run sync:registries` тощо.

## Що тут

Ця директорія містить скрипти та файли з початкового етапу збору даних з 11 реєстрів НАІС (https://nais.gov.ua/pass_opendata):

1. Єдиний державний реєстр юридичних осіб, фізичних осіб-підприємців та громадських формувань
2. Єдиний реєстр нотаріусів
3. Державний реєстр атестованих судових експертів
4. Єдиний реєстр спеціальних бланків нотаріальних документів
5. Реєстр методик проведення судових експертиз
6. Єдиний реєстр підприємств, щодо яких порушено впровадження у справі про банкрутство
7. Єдиний реєстр арбітражних керуючих України
8. Єдиний державний реєстр нормативно-правових актів
9. Словник адміністративно-територіального устрою України та словник вулиць
10. Інформація з автоматизованої системи виконавчого провадження
11. Єдиний реєстр боржників

## Файли

- `scrape-nais.js`, `scrape-all-pages.js` -- скрапери для збору посилань на завантаження
- `import-notaries.js`, `import-legal-entities.js` -- ранні скрипти імпорту
- `schema.sql` -- початкова схема БД (замінена міграціями MCP-сервера)
- `docker-compose.yml` -- локальний PostgreSQL для дослідження
- `*.md` -- документація початкового етапу
